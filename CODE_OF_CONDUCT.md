# Code of Conduct

## Purpose

This project aims to maintain a respectful, professional, and productive environment for development and collaboration.

## Expected Behaviour

Contributors should:

* Communicate respectfully and professionally.
* Provide constructive feedback.
* Follow good coding practices.
* Write clear commit messages and documentation.
* Report bugs and issues responsibly.

## Unacceptable Behaviour

The following behaviours are not acceptable:

* Harassment, discrimination, or offensive communication.
* Personal attacks or disrespectful behaviour.
* Introducing malicious or harmful code.
* Sharing private information without permission.

## Reporting Issues

Any issues related to the project should be reported through the GitHub Issues section of the repository.

By contributing to this project, you agree to follow this Code of Conduct and help maintain a positive development environment.
