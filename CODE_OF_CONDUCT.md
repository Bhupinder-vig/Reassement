# Code of Conduct

## Purpose

This project aims to maintain a respectful and professional development environment.

## Expected Behaviour

Contributors should:

* Communicate respectfully with others.
* Provide constructive feedback.
* Follow good coding practices.
* Write clear commit messages and documentation.
* Report bugs and issues responsibly.

## Unacceptable Behaviour

The following are not allowed:

* Harassment or discrimination.
* Offensive or disrespectful communication.
* Introducing malicious code.
* Sharing private information without permission.

## Reporting Issues

Any concerns or issues should be reported through the GitHub Issues section of the repository.

By contributing to this project, you agree to follow this Code of Conduct.
